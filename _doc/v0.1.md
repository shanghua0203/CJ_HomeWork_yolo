## 🛠️ v0.1 開發順序

| 順序 | 檔案 | 說明 |
|:---:|------|------|
| 1 | 建立資料夾結構 | - |
| 2 | config.yaml + requirements.txt | 模型/影片路徑等設定 |
| 3 | detector.py | YOLO 偵測乒乓球，輸出 (x, y) 座標<br>**單元測試**：輸入一張照片，驗證輸出為一個 (x, y) |
| 4 | filter.py | **(新增)** 過濾雜訊，確保座標合理<br>例如：濾除超出畫面範圍、瞬間跳動過大的點 |
| 5 | tracker.py | 記錄連續幀座標，繪製軌跡線<br>**掉幀處理**：球消失 1-2 格時，用線性插值連線 |
| 6 | landing_detector.py | 分析 Y 軸反轉點（彈跳點）<br>**單元測試**：針對各種 Y 軸變化模式測試 |
| 7 | perspective.py | 透視變換矩陣<br>**功能**：滑鼠點選四點（自動/手動）設定轉換 |
| 8 | visualizer.py | 整合輸出軌跡、落點、2D 鳥瞰圖 |
| 9 | main.py + 系統測試 | 串接所有模組，端到端測試 |

## 🔧 技術細節備註

- **掉幀處理邏輯**：當球消失時，先暫存上一個座標，若 1-2 幀內重新出現，則用線性插值補間
- **雜訊過濾**：濾除座標 < 0 或 > 畫面寬高、相鄰兩幀距離異常大（球瞬間跳遷）的點
- **落點判斷**：Y 軸數值變大（球下落）→ 突然變小（反彈）→ 取反彈前的最低點為落點
